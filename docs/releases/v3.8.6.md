Live gegen den Server geprüft: ein `delivery:"queue"`-Prompt verlässt die Inbox in dem Moment, in
dem er zugestellt wird, und wird eine Nachricht **mit derselben ID** — der Server war also sauber,
die App nicht. Die optimistische Queue-Zeile blieb hängen (und der Prompt stand doppelt im Chat),
weil sie nur auf ein Event oder einen späteren Reload wartete. Jetzt entscheidet das Transcript:
**was schon als Nachricht da ist, ist nicht mehr in der Queue** — selbstheilend, ohne auf ein Event
zu hoffen. Zusätzlich wird die Inbox am Turn-Ende neu gelesen, also genau dann, wenn ein wartender
Prompt zugestellt wird.

## Install

1. Download the APK to your phone.
2. Allow **"Install unknown apps"** for your browser / file manager when prompted.
3. Open the APK and install.
4. Launch the app and enter your OpenCode server address, e.g.
   `http://192.168.1.100:4096` (the app starts on a backend picker; no server is
   baked in).

Updates install straight over previous versions, because every release is signed
with the same key.

## Requirements

- Android **7.0 (API 25)** or newer.
- A reachable OpenCode server exposing its HTTP API (e.g. `opencode serve`),
  on the same LAN, VPN or tunnel as the phone.

## Highlights

- **Live streaming chat** over SSE with a stable running indicator, progressive
  Markdown and syntax-highlighted code.
- **Inline tool calls** — shell, read, edit and diff rows, with consecutive
  identical calls collapsed.
- **Permission prompts & agent questions** answerable in-app or from a
  notification action.
- **Per-session model / agent / variant selection**, synced with the server.
- **Provider management** — browse the catalog, connect or disconnect
  credentials.
- **Review / Changes tab** with branch badge and on-demand working-tree diff.
- **Sessions & history** — project grouping, offline cache, older-message
  paging and history search.
- **Background continuity** — foreground session service, home-screen widget and
  a Quick Settings tile.
- **Share target** for text and images; multiple themes and custom fonts.
